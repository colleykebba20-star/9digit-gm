# 9Digit GM

A simple tool for converting Gambian 7-digit phone numbers to the new 9-digit format.

## Features

- Convert individual phone numbers
- Convert multiple contacts
- Support for QCell, Africell and Comium
- CSV and VCF contact files
- D25 bulk conversion service
- Wave payment integration

## Important

Numbering prefixes will be based on the official Gambian numbering plan.
